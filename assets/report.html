Interim mitigations

Patch to 8.5.12, 8.4.27, 8.3.36 or 8.2.35. These settings only reduce exposure until then.

  • CVE-2026-109618: set memory_limit=-1 so applications cannot override it.
  • CVE-2026-109619: set session.upload_progress.enabled=0, and on PHP 8.5 also set fatal_error_backtraces=0.
  • Restart every PHP worker after changing settings. mod_php is the riskiest deployment, because an unauthenticated request reaches the flaw before any application code runs.
  • Status is based on the PHP version, so distro packages with backported fixes can show as vulnerable. Check those against the vendor advisory.
